# 41889 Assignment 3 — Word Order (IOS)

The app is a simple word scramble game: you pick a topic and difficulty, then drag letters into the slots to spell the word before the timer runs out. Scores get saved locally so you can check the scoreboard after.

## How to run it

1. Clone or download this repo.
2. Open **`Prototype/Prototype.xcodeproj`** in Xcode.
3. Choose an iPhone simulator (or your own device) and press **Run**.


## What’s in the app

- Home screen with start, scoreboard, and tutorial  
- Settings: enter your name, choose topic (animals, fruits, etc.) and difficulty (changes time limit and scoring)  
- Game screen with timer, picture hint, letter bank, check / skip  
- Results screen when you finish, and high scores stored on the device
